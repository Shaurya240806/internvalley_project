About the project

A university project demonstrating confidentiality, authentication and secure file handling with Python.

Abstract

This application lets registered users encrypt images with AES-256-GCM, protect the encryption keys with RSA-OAEP, and send the result to other users over an authenticated web interface. It combines symmetric and asymmetric cryptography in a hybrid design, the same pattern used by TLS and secure email.
